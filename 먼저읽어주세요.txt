발주관리앱 (Order Management)
=================================

1. 실행 방법
- "앱시작.cmd" 를 더블클릭하면 서버가 실행되고 기본 브라우저로 앱이 열립니다.
- 주소: http://127.0.0.1:3000
- 종료하려면 "앱종료.cmd" 를 사용하세요. (종료 직전 자동 백업이 만들어집니다)

2. 필요한 환경
- Windows 10/11
- Node.js 22.5 이상 (없다면 https://nodejs.org 에서 LTS 설치 후 다시 실행)
- 별도 데이터베이스 설치는 필요 없습니다. (JSON 파일로 저장)

3. 데이터 저장 위치
- data 폴더    : 실제 업무 데이터 (발주, 실적, 계획 등) — JSON 파일
- backup 폴더  : 자동/수동/복원전/종료 백업 스냅샷
- logs 폴더    : 서버 로그와 실행 PID
- seed 폴더    : 첫 실행 시 사용되는 기본 구조(ITEM별 BUDGET 기준값)
  ※ data 폴더는 첫 실행 때 seed 값으로 자동 생성됩니다.

4. 주요 기능
- 신규 발주 : 업체·아이템(D/F/G/H/I/J/ETC)·모델·수량·금액·발주일·납기일 등록
- 발주 및 납품 관리 : 목록/검색/필터, 납품·계산서 완료 처리, 일괄 처리, 데이터 점검
- 통합분석 : 월별 발주·세금계산서 금액, 거래처별 분석, 월별 상세 팝업
- 연간영업실적 및 계획 : BUDGET 대비 실적, ITEM별 BUDGET(4분기 NEW BUDGET 입력), 거래금액별 업체, 연도별 업무분석
- 월간회의 : 월 결과, 발주/계산서 예상(매월 반복 4건 + 자동/직접 추가), 월 주요 계획
- 데이터 관리 : 엑셀 가져오기/내보내기, 지금 백업, 백업 목록·복원, JSON 백업/복원, 제출용 HTML 생성

5. 백업 · 복원
- "지금 백업" 또는 "백업 목록 · 복원" 으로 언제든 백업/복원할 수 있습니다.
- 복원 직전 현재 상태는 "복원 전 백업"으로 자동 보관됩니다.
- "JSON 백업 다운로드"로 전체 데이터를 파일로 내려받아 다른 PC로 옮길 수 있습니다.

6. 엑셀 기능
- 최초 실행 시 엑셀 라이브러리(xlsx)를 인터넷에서 자동으로 내려받습니다.
- 인터넷이 없거나 실패한 경우, 엑셀 가져오기/내보내기 버튼을 누르면 안내가 표시되며
  앱의 나머지 기능은 정상 동작합니다.

7. 제출용 HTML
- "제출용 HTML 생성"으로 현재 데이터를 고정한 오프라인 파일(.html)을 만들 수 있습니다.
- 이 파일은 서버/앱 없이 더블클릭으로 열리며, 이메일 첨부용으로 사용할 수 있습니다.

주의
- data 와 backup 폴더는 정기적으로 함께 보관(복사)해 두시기 바랍니다.
- 폴더를 다른 위치로 옮길 때는 data, backup 폴더를 함께 옮기면 데이터가 유지됩니다.
